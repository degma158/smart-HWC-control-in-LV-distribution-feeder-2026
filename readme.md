This is the code used to implement the simulation, modelling, and analysis for the comparitive study of decentralised HWC control strategies for a New Zealand low-voltage distribution feeder.
Auther: Max de Groot

It contains simulation and modelling code within the folder 'My Code', and analysis code within the folder 'Results'.

## Note on File Paths
This repository was recreated in a new location during final project organisation. As a result, some file paths differ from those used during development. The files in this repository reflect the final project structure.
